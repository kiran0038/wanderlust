# 🌍 Wanderlust Country Guide
An interactive, responsive travel guide web application that helps travelers discover tourist attractions, transit options, daily budget estimates, and famous local foods across top global destinations.
🔗 **Live Website**: [wanderlust-phi-seven.vercel.app](https://wanderlust-phi-seven.vercel.app/)
---
## ✨ Features
- **6 Global Destinations**: Japan, Italy, India, France, Thailand, and Switzerland.
- **Top Attractions**: Detailed cards with photos, highlights, and best visiting seasons.
- **Logistics & Transit**: Practical tips on airports, trains, and local public transit.
- **Budget & Currency Converter**: Daily travel cost breakdowns with currency conversion.
- **Food & Cuisine**: Must-try iconic dishes and street eats for every country.
## 🛠️ Built With
- **Framework**: Next.js & React
- **Styling**: Tailwind CSS & Lucide Icons
- **Deployment**: Vercel
- **Version Control**: GitHub
